# okf-drone-skill

An Open Knowledge Format (OKF) bundle grounds an agent skill. The skill plans one drone mission,
validates the plan against the bundle, scores the risk with EASA SORA 2.5, and writes a
go / no-go report for a human to sign.

Status: design. See [`docs/specs/2026-09-28-okf-drone-skill-v1-design.md`](docs/specs/2026-09-28-okf-drone-skill-v1-design.md).

Template and method: [okf-grc-skill](https://github.com/cdevarenne/okf-grc-skill).
