# Hazards

The rows of the flight-plan risk matrix (S10 §6). Each hazard has a likelihood and a severity
from 1 (very low) to 5 (very high). The score is likelihood x severity. The residual risk is the
value in S10 after the mitigations.

* [Loss of C2 link](loss-of-c2.md) - L2 x S4
* [GPS signal loss or jamming](gps-jamming.md) - L1 x S4
* [Battery failure or low battery](low-battery.md) - L2 x S3
* [Mid-air collision with manned aircraft](midair-manned.md) - L1 x S5
* [Mid-air collision with other small UAS](midair-suas.md) - L2 x S3
* [Collision with a ground obstacle](obstacle-ground.md) - L2 x S3
* [Loss of visual line of sight](loss-of-vlos.md) - L2 x S3
* [Public interference or disturbance](public-interference.md) - L2 x S2
* [Payload malfunction](payload-malfunction.md) - L2 x S2
* [Extreme weather change](weather-change.md) - L2 x S4
